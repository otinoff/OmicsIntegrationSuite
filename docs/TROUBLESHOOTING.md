# Руководство по устранению неполадок

## Введение

Это руководство по устранению неполадок поможет вам диагностировать и решить наиболее распространенные проблемы, которые могут возникнуть при использовании платформы диагональной интеграции мультимодальных биологических данных. Документ охватывает проблемы, связанные с установкой, конфигурацией, обработкой данных и производительностью.

## Диагностика проблем

### Системные проверки

Перед началом устранения неполадок рекомендуется выполнить следующие системные проверки:

1. **Проверка версии Python:**
   ```bash
   python --version
   python3 --version
   ```

2. **Проверка установленных зависимостей:**
   ```bash
   pip list
   ```

3. **Проверка свободного места на диске:**
   ```bash
   # Linux/macOS
   df -h
   
   # Windows (в PowerShell)
   Get-PSDrive
   ```

4. **Проверка доступной оперативной памяти:**
   ```bash
   # Linux/macOS
   free -h
   
   # Windows (в PowerShell)
   Get-WmiObject -Class Win32_OperatingSystem | Select-Object TotalVisibleMemorySize, FreePhysicalMemory
   ```

5. **Проверка прав доступа к файлам:**
   ```bash
   # Linux/macOS
   ls -la data/
   
   # Windows (в PowerShell)
   Get-Acl data\
   ```

### Анализ логов

Логи являются ключевым инструментом для диагностики проблем. Основные файлы логов:

- `logs/app.log` - Основной лог приложения
- `logs/error.log` - Логи ошибок
- `logs/performance.log` - Логи производительности
- `modules/*/logs/` - Логи каждого модуля

Формат логов:
```
[YYYY-MM-DD HH:MM:SS,mmm] [LEVEL] [MODULE] Сообщение
```

Где LEVEL может быть:
- DEBUG - Отладочная информация
- INFO - Информационные сообщения
- WARNING - Предупреждения
- ERROR - Ошибки
- CRITICAL - Критические ошибки

### Использование встроенных инструментов диагностики

Платформа включает встроенные инструменты диагностики:

```bash
# Запуск диагностики системы
python run.py --diagnose

# Проверка конфигурации
python run.py --validate-config

# Тестирование подключения к данным
python run.py --test-data-access

# Проверка производительности
python run.py --benchmark
```

## Проблемы с установкой

### Python не найден

**Симптомы:**
```
'python' is not recognized as an internal or external command
```

**Решение:**
1. Убедитесь, что Python установлен:
   - Перейдите на https://www.python.org/downloads/
   - Скачайте и установите последнюю версию Python
   - Убедитесь, что выбрана опция "Add Python to PATH" во время установки

2. Проверьте переменную окружения PATH:
   ```bash
   echo $PATH  # Linux/macOS
   echo %PATH%  # Windows
   ```

3. Если Python установлен, но не находится в PATH:
   - Добавьте путь к Python в переменную окружения PATH
   - Перезапустите терминал/командную строку

### Ошибки установки зависимостей

**Симптомы:**
```
ERROR: Could not find a version that satisfies the requirement package_name
```

**Решение:**
1. Обновите pip:
   ```bash
   python -m pip install --upgrade pip
   ```

2. Попробуйте установить зависимости по одной:
   ```bash
   pip install numpy
   pip install pandas
   # и так далее для каждой зависимости
   ```

3. Используйте альтернативный индекс пакетов:
   ```bash
   pip install -r requirements.txt -i https://pypi.org/simple/
   ```

4. Если проблема с конкретным пакетом:
   - Проверьте совместимость версий
   - Попробуйте установить предыдущую версию пакета
   - Обратитесь к документации пакета

### Проблемы с правами доступа

**Симптомы:**
```
PermissionError: [Errno 13] Permission denied
```

**Решение:**
1. Запустите установку с правами администратора:
   ```bash
   # Linux/macOS
   sudo pip install -r requirements.txt
   
   # Windows (в командной строке от имени администратора)
   pip install -r requirements.txt
   ```

2. Используйте виртуальное окружение:
   ```bash
   python -m venv myenv
   source myenv/bin/activate  # Linux/macOS
   myenv\Scripts\activate     # Windows
   pip install -r requirements.txt
   ```

3. Проверьте права доступа к директории установки

### Проблемы с сетью при установке

**Симптомы:**
```
Could not connect to pypi.org
```

**Решение:**
1. Проверьте подключение к интернету:
   ```bash
   ping pypi.org
   ```

2. Используйте прокси (если требуется):
   ```bash
   pip install -r requirements.txt --proxy http://user:password@proxyserver:port
   ```

3. Скачайте пакеты вручную и установите из локальных файлов:
   ```bash
   pip download -r requirements.txt -d packages/
   pip install --find-links packages/ -r requirements.txt
   ```

## Проблемы с конфигурацией

### Неверный формат конфигурационных файлов

**Симптомы:**
```
yaml.scanner.ScannerError: while scanning a simple key
```

**Решение:**
1. Проверьте синтаксис YAML файла:
   - Используйте онлайн-валидаторы YAML
   - Убедитесь в правильности отступов (только пробелы, 2 пробела на уровень)
   - Проверьте парные символы (кавычки, скобки)

2. Пример корректного конфигурационного файла:
   ```yaml
   module:
     name: "Genomics Module"
     version: "1.0.0"
     threads: 4
   
   processing:
     input_format: "fastq"
     output_format: "bam"
   ```

3. Используйте встроенный валидатор:
   ```bash
   python run.py --validate-config
   ```

### Отсутствующие параметры конфигурации

**Симптомы:**
```
KeyError: 'required_parameter'
```

**Решение:**
1. Проверьте наличие всех обязательных параметров в конфигурационных файлах:
   - `config/config.yaml`
   - `modules/*/config/config.yaml`

2. Сравните конфигурационные файлы с примерами из документации

3. Восстановите значения по умолчанию из шаблонов конфигурации

### Проблемы с путями в конфигурации

**Симптомы:**
```
FileNotFoundError: [Errno 2] No such file or directory
```

**Решение:**
1. Проверьте правильность указания путей:
   - Используйте абсолютные пути или относительные пути от корня проекта
   - Убедитесь, что директории существуют
   - Проверьте права доступа к директориям

2. Пример корректных путей:
   ```yaml
   paths:
     input_dir: "/absolute/path/to/input"
     output_dir: "./relative/path/to/output"
     temp_dir: "${TEMP}/platform_temp"  # Использование переменных окружения
   ```

## Проблемы с обработкой данных

### Ошибки форматов входных данных

**Симптомы:**
```
ValueError: Invalid file format
UnsupportedFormatError: File extension .xyz is not supported
```

**Решение:**
1. Проверьте формат входных файлов:
   - Убедитесь, что файлы имеют правильные расширения
   - Проверьте структуру файлов на соответствие спецификации

2. Поддерживаемые форматы по модальностям:
   - **Геномные данные**: FASTQ, BAM/CRAM, VCF
   - **Транскриптомные данные**: FASTQ, матричные тройки, Loom, Seurat
   - **Данные микроРНК**: FASTQ, готовые матрицы подсчетов
   - **Протеомные данные**: RAW файлы, готовые таблицы идентификации
   - **Метаболомные данные**: RAW файлы, peak tables

3. Конвертируйте файлы в поддерживаемые форматы:
   ```bash
   # Пример конвертации BAM в FASTQ
   samtools fastq input.bam > output.fastq
   ```

### Проблемы с объемом данных

**Симптомы:**
```
MemoryError: Unable to allocate array with shape
OSError: [Errno 28] No space left on device
```

**Решение:**
1. Проверьте доступную память и место на диске:
   ```bash
   free -h  # Linux/macOS
   df -h    # Linux/macOS
   ```

2. Уменьшите объем обрабатываемых данных:
   - Обрабатывайте данные по частям
   - Используйте сэмплинг данных
   - Увеличьте виртуальную память

3. Оптимизируйте параметры обработки:
   - Уменьшите количество параллельных потоков
   - Используйте более эффективные алгоритмы
   - Включите сжатие промежуточных данных

### Ошибки при выравнивании данных

**Симптомы:**
```
AlignmentError: Failed to align reads
RuntimeError: BWA index not found
```

**Решение:**
1. Проверьте наличие референсных геномов:
   - Убедитесь, что индексы референсных геномов существуют
   - Проверьте пути к референсным геномам в конфигурации

2. Пересоздайте индексы референсных геномов:
   ```bash
   # Для BWA
   bwa index reference_genome.fasta
   
   # Для STAR
   STAR --runMode genomeGenerate --genomeDir /path/to/index --genomeFastaFiles reference_genome.fasta
   ```

3. Проверьте совместимость версий инструментов и референсных геномов

### Проблемы с вызовом вариантов

**Симптомы:**
```
VariantCallingError: Failed to call variants
ValueError: Invalid VCF format
```

**Решение:**
1. Проверьте качество выравненных данных:
   - Убедитесь, что BAM файлы корректны
   - Проверьте покрытие и глубину секвенирования

2. Проверьте параметры вызова вариантов:
   - Убедитесь, что параметры соответствуют типу данных
   - Проверьте пороговые значения качества

3. Используйте альтернативные инструменты вызова вариантов:
   ```bash
   # GATK
   gatk HaplotypeCaller -I input.bam -O output.vcf
   
   # bcftools
   bcftools mpileup -f reference.fasta input.bam | bcftools call -mv -O vcf -o output.vcf
   ```

## Проблемы с производительностью

### Медленная обработка данных

**Симптомы:**
- Длительное время обработки
- Высокая загрузка процессора
- Медленный отклик интерфейса

**Решение:**
1. Оптимизируйте параметры параллелизма:
   ```yaml
   # config/config.yaml
   processing:
     threads: 8  # Увеличьте количество потоков
     chunk_size: 1000000  # Оптимизируйте размер блоков обработки
   ```

2. Используйте более эффективные алгоритмы:
   - Выберите оптимальные параметры для каждого инструмента
   - Используйте специализированные версии инструментов (например, BWA-MEM2)

3. Убедитесь, что используются SSD накопители для входных и выходных данных

4. Закройте другие ресурсоемкие приложения во время обработки

### Проблемы с памятью

**Симптомы:**
```
MemoryError: Unable to allocate array
OutOfMemoryError: Java heap space
```

**Решение:**
1. Увеличьте лимиты памяти:
   ```bash
   # Для Java приложений
   export JAVA_OPTS="-Xmx16g"
   
   # Для Python приложений
   ulimit -v 16777216  # 16 ГБ в килобайтах
   ```

2. Используйте обработку данных по частям:
   - Разделите большие файлы на меньшие части
   - Используйте потоковую обработку вместо загрузки всего файла в память

3. Оптимизируйте структуры данных:
   - Используйте более эффективные типы данных (например, int32 вместо int64)
   - Используйте сжатие данных в памяти

### Проблемы с диском

**Симптомы:**
```
OSError: [Errno 28] No space left on device
IOError: [Errno 5] Input/output error
```

**Решение:**
1. Очистите временные файлы:
   ```bash
   # Удалите временные файлы
   rm -rf data/temp/*
   rm -rf logs/*.log
   ```

2. Освободите место на диске:
   - Удалите ненужные файлы
   - Архивируйте старые данные
   - Используйте внешние накопители для хранения промежуточных данных

3. Используйте сжатие данных:
   - Включите сжатие BAM/CRAM файлов
   - Используйте сжатие VCF файлов (VCF.gz)

4. Проверьте настройки брандмауэра:
   - Убедитесь, что брандмауэр не блокирует доступ к порту веб-интерфейса

### Проблемы с командной строкой

**Симптомы:**
```
Unknown option: --invalid-option
Invalid command: unknown_command
```

**Решение:**
1. Проверьте синтаксис команд:
   ```bash
   python run.py --help
   ```

2. Используйте корректные параметры командной строки:
   ```bash
   # Правильно
   python run.py --module genomics --input data/input --output data/output
   
   # Неправильно
   ```

   ```bash
   pip install --upgrade multimodal-bio-data-integration
   ```

## Проблемы с интеграцией

### Ошибки при диагональной интеграции

**Симптомы:**
```
IntegrationError: Failed to integrate modalities
MismatchError: Sample identifiers do not match
```

**Решение:**
1. Проверьте идентификаторы образцов:
   - Убедитесь, что идентификаторы образцов согласованы между модальностями
   - Проверьте формат идентификаторов

2. Проверьте перекрытие образцов:
   - Убедитесь, что есть достаточное перекрытие образцов между модальностями
   - Проверьте качество данных для каждого образца

3. Используйте алгоритмы импутации:
   ```python
   # Пример использования алгоритмов импутации
   from modules.integration.imputation import knn_impute
   
   imputed_data = knn_impute(raw_data, k=5)
   ```

### Проблемы с контролем качества

**Симптомы:**
```
QCError: Quality control failed
ValidationError: Data does not meet quality thresholds
```

**Решение:**
1. Проверьте метрики качества:
   - Убедитесь, что данные соответствуют минимальным требованиям качества
   - Проверьте параметры фильтрации в конфигурации

2. Отрегулируйте пороговые значения:
   ```yaml
   # config/qc_config.yaml
   thresholds:
     min_coverage: 30  # Уменьшите минимальное покрытие
     min_mapping_quality: 20  # Уменьшите минимальное качество выравнивания
   ```

3. Используйте альтернативные метрики качества:
   - Выберите метрики, соответствующие вашим данным
   - Настройте веса метрик в зависимости от приоритетов

## Специфические проблемы по модальностям

### Геномные данные

#### Проблемы с FASTQ файлами

**Симптомы:**
```
FastQError: Invalid FASTQ format
QualityEncodingError: Unsupported quality encoding
```

**Решение:**
1. Проверьте формат FASTQ файлов:
   - Убедитесь, что файлы соответствуют формату FASTQ
   - Проверьте кодировку качества (Sanger, Illumina 1.3+, Solexa)

2. Используйте инструменты для проверки качества:
   ```bash
   fastqc input.fastq
   ```

3. Конвертируйте файлы при необходимости:
   ```bash
   # Конвертация кодировки качества
   seqtk seq -V input.fastq > output.fastq
   ```

#### Проблемы с BAM/CRAM файлами

**Симптомы:**
```
BamError: Invalid BAM file
IndexError: BAM index not found
```

**Решение:**
1. Проверьте целостность BAM файлов:
   ```bash
   samtools quickcheck input.bam
   ```

2. Создайте индексы при необходимости:
   ```bash
   samtools index input.bam
   ```

3. Проверьте заголовки BAM файлов:
   ```bash
   samtools view -H input.bam
   ```

### Транскриптомные данные

#### Проблемы с bulk RNA-seq

**Симптомы:**
```
TranscriptomicsError: Failed to quantify expression
AlignmentError: Poor mapping rate
```

**Решение:**
1. Проверьте качество RNA:
   - Убедитесь, что данные не деградированы
   - Проверьте уровень rRNA-контаминации

2. Оптимизируйте параметры выравнивания:
   ```bash
   # STAR
   STAR --genomeDir /path/to/index --readFilesIn read1.fastq read2.fastq --outFileNamePrefix output_
   ```

3. Используйте альтернативные инструменты:
   - HISAT2 для выравнивания
   - Salmon/kallisto для псевдо-выравнивания

#### Проблемы с scRNA-seq

**Симптомы:**
```
SingleCellError: Failed to process single-cell data
MatrixError: Invalid matrix format
```

**Решение:**
1. Проверьте формат матричных файлов:
   - Убедитесь, что файлы matrix.mtx, barcodes.tsv, features.tsv корректны
   - Проверьте размеры матриц

2. Проверьте качество клеток:
   - Убедитесь, что клетки проходят фильтрацию качества
   - Проверьте количество детектируемых генов на клетку

3. Используйте инструменты диагностики:
   ```python
   import scanpy as sc
   
   # Загрузка данных
   adata = sc.read_10x_mtx('path/to/data/')
   
   # Базовая диагностика
   sc.pl.highest_expr_genes(adata)
   ```

### Данные микроРНК

#### Проблемы с обрезкой адаптеров

**Симптомы:**
```
AdapterError: Failed to trim adapters
LengthError: Invalid read length after trimming
```

**Решение:**
1. Проверьте последовательности адаптеров:
   - Убедитесь, что используются правильные последовательности адаптеров
   - Проверьте версии протоколов

2. Отрегулируйте параметры обрезки:
   ```bash
   cutadapt -a ADAPTER_SEQUENCE -m 18 -M 25 input.fastq -o output.fastq
   ```

3. Используйте инструменты для анализа качества после обрезки:
   ```bash
   fastqc output.fastq
   ```

### Протеомные данные

#### Проблемы с RAW файлами

**Симптомы:**
```
RawFileError: Unsupported RAW file format
ConversionError: Failed to convert RAW file
```

**Решение:**
1. Проверьте совместимость форматов:
   - Убедитесь, что версия ProteoWizard поддерживает формат файла
   - Проверьте производителя масс-спектрометра

2. Обновите инструменты:
   ```bash
   # Установка последней версии ProteoWizard
   conda install -c bioconda proteowizard
   ```

3. Используйте альтернативные инструменты конвертации:
   ```bash
   # MSConvertGUI для графического интерфейса
   # Или командная строка:
   msconvert input.raw --mzML
   ```

### Метаболомные данные

#### Проблемы с peak picking

**Симптомы:**
```
PeakPickingError: Failed to detect peaks
NoiseError: High noise level in spectra
```

**Решение:**
1. Оптимизируйте параметры peak picking:
   ```r
   # XCMS
   cwp <- CentWaveParam(ppm=25, peakwidth=c(10,60))
   ```

2. Предварительная обработка данных:
   - Выполните нормализацию базового шума
   - Примените фильтрацию низкокачественных спектров

3. Используйте визуализацию для диагностики:

## Проблемы с безопасностью

### Проблемы с правами доступа

**Симптомы:**
```
PermissionError: [Errno 13] Permission denied
AccessDeniedError: Access to resource denied
```

**Решение:**
1. Проверьте права доступа к файлам:
   ```bash
   # Linux/macOS
   ls -la data/
   
   # Windows
   icacls data\
   ```

2. Измените права доступа при необходимости:
   ```bash
   # Linux/macOS
   chmod 755 data/
   chown user:user data/
   
   # Windows
   icacls data\ /grant Users:F
   ```

3. Используйте виртуальное окружение:
   ```bash
   python -m venv platform_env
   source platform_env/bin/activate  # Linux/macOS
   platform_env\Scripts\activate       # Windows
   ```

### Проблемы с шифрованием

**Симптомы:**
```
EncryptionError: Failed to encrypt data
DecryptionError: Failed to decrypt data
```

**Решение:**
1. Проверьте ключи шифрования:
   - Убедитесь, что ключи шифрования доступны
   - Проверьте правильность паролей

2. Используйте встроенные инструменты для управления ключами:
   ```bash
   # Генерация новых ключей
   python run.py --generate-keys
   
   # Проверка ключей
   python run.py --validate-keys
   ```

3. Обратитесь к руководству администратора для восстановления ключей
