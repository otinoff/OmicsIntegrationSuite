# Руководство пользователя

## Введение

Это руководство пользователя предназначено для исследователей и биоинформатиков, работающих с платформой диагональной интеграции мультимодальных биологических данных. Документ описывает основные функции приложения, способы его использования и лучшие практики работы с данными.

## Общее описание платформы

Платформа диагональной интеграции мультимодальных биологических данных предназначена для унификации и контроля качества шести основных типов биологических данных:

1. **Геномные данные** (FASTQ, BAM/CRAM, VCF)
2. **Транскриптомные данные** (bulk RNA-seq и scRNA-seq)
3. **Данные микроРНК** (miRNA-seq)
4. **Протеомные данные** (RAW файлы масс-спектрометров)
5. **Метаболомные данные** (MS данные и peak tables)
6. **Интеграционные данные** (объединение данных различных модальностей)

## Начало работы

### Подготовка данных

Перед началом работы с платформой необходимо подготовить данные в соответствующих форматах:

#### Геномные данные
- Файлы FASTQ от платформ секвенирования Illumina, PacBio, Oxford Nanopore Technologies
- Файлы SAM/BAM/CRAM от любых выравнивателей
- Файлы VCF от внешних пайплайнов

#### Транскриптомные данные
- Файлы FASTQ от секвенаторов Illumina и других платформ
- Готовые матрицы подсчётов в форматах CSV, TSV, Excel
- Файлы матричных троек (matrix.mtx + barcodes.tsv + features.tsv) для scRNA-seq
- Файлы Loom (.loom) и Seurat объекты (.rds) для scRNA-seq

#### Данные микроРНК
- Файлы FASTQ от различных секвенирующих платформ
- Готовые матрицы подсчётов в табличных форматах

#### Протеомные данные
- Проприетарные RAW файлы (Thermo, Bruker и других производителей)
- Готовые таблицы идентификации и квантификации в табличных форматах

#### Метаболомные данные
- RAW файлы различных масс-спектрометров
- Готовые peak table в табличных форматах

### Организация файлов данных

## Использование платформы

### Запуск основного приложения

Для запуска основного приложения используйте команду:

```bash
python run.py
```

При запуске откроется интерактивное меню с выбором модуля для обработки.

### Запуск конкретного модуля

Для запуска конкретного модуля используйте параметр `--module`:

```bash
python run.py --module genomics --input data/input/genomics --output data/output/genomics
```

Доступные модули:
- `genomics` - обработка геномных данных
- `transcriptomics` - обработка транскриптомных данных
- `mirna` - обработка данных микроРНК
- `proteomics` - обработка протеомных данных
- `metabolomics` - обработка метаболомных данных
- `integration` - диагональная интеграция данных
- `qc` - контроль качества данных
- `reporting` - генерация отчетов

### Использование веб-интерфейса

Если установлен Streamlit, можно запустить веб-интерфейс:

```bash
python run.py --gui
```

Или напрямую через Streamlit:
```bash
streamlit run web_interface.py
```

Веб-интерфейс предоставляет удобный способ загрузки файлов, отслеживания прогресса обработки и просмотра результатов.

## Обработка данных по модальностям

### Геномные данные

Модуль обработки геномных данных поддерживает следующие функции:

1. **Контроль качества сырых ридов** с использованием FastQC
2. **Выравнивание ридов** на референсный геном с использованием BWA-MEM2/Minimap2
3. **Сортировка и индексация** BAM/CRAM файлов с использованием samtools
4. **Вызов вариантов** с использованием bcftools/GATK
5. **Валидация вариантов** через фильтрацию по качеству, глубине и частоте аллелей

Выходные форматы:
- BAM/CRAM с корректными заголовками и индексами
- VCF/gVCF, соответствующие спецификации версии 4.3 и выше

### Транскриптомные данные

Модуль обработки транскриптомных данных поддерживает обработку как bulk RNA-seq, так и scRNA-seq данных:

#### Bulk RNA-seq
1. **Предобработка ридов** с использованием fastp
2. **Выравнивание** на референсный геном с использованием STAR/HISAT2
3. **Подсчет экспрессии** с использованием featureCounts/HTSeq
4. **Нормализация данных** и контроль качества экспрессионных профилей

Выходной формат: таблица counts.tsv с колонками gene_id, sample_id и count

#### ScRNA-seq
1. **Обработка матричных троек** файлов
2. **Конвертация** в формат H5AD
3. **Фильтрация клеток** по качеству
4. **Нормализация** данных

Выходной формат: файл H5AD с обязательными полями: матрица экспрессии X, метаданные клеток obs, аннотация генов var

### Данные микроРНК

Модуль обработки данных микроРНК включает:

1. **Обрезку адаптеров** и фильтрацию по длине с cutadapt
2. **Выравнивание** на референсы miRBase с Bowtie/STAR
3. **Подсчет** экспрессии микроРНК

Выходной формат: таблица counts.tsv с колонками miRNA_id, sample_id, count

### Протеомные данные

Модуль обработки протеомных данных поддерживает:

1. **Конвертацию** проприетарных RAW файлов в открытый формат mzML с ProteoWizard MSConvert
2. **Идентификацию и квантификацию** с MaxQuant/DIA-NN/FragPipe
3. **Обработку** готовых таблиц идентификации и квантификации

Выходные форматы: раздельные таблицы proteins.tsv и peptides.tsv

### Метаболомные данные

Модуль обработки метаболомных данных включает:

1. **Конвертацию** RAW файлов в mzML с ProteoWizard MSConvert
2. **Пик-пикинг** и выравнивание с XCMS
3. **Аннотацию** соединений с MS-DIAL/CAMERA
4. **Квантификацию** метаболитов

Выходной формат: унифицированная таблица peak_table.csv

### Диагональная интеграция

Модуль диагональной интеграции позволяет объединять разнотипные биологические данные при неполном перекрытии образцов между модальностями:

1. **Сопоставление образцов** между различными модальностями
2. **Алгоритмы импутации** для восстановления пропущенных значений
3. **Нормализация данных** для совместимости между модальностями

## Контроль качества

Платформа включает встроенный модуль контроля качества, который автоматически проверяет:

- Качество сырых данных
- Корректность выполнения алгоритмов обработки
- Соответствие биологическим закономерностям

Для запуска контроля качества используйте команду:

```bash
python run.py --module qc --input data/input --output data/output/qc
```

## Генерация отчетов

Платформа автоматически генерирует унифицированные отчеты контроля качества, содержащие:

- Основные метрики качества для каждой модальности
- Графическое представление ключевых показателей
- Рекомендации по интерпретации результатов
- Информацию о версиях используемых инструментов и референсных баз

Для генерации отчетов используйте команду:

```bash
python run.py --module reporting --input data/output --output data/output/reports
```

3. Используйте несколько методов анализа для подтверждения выводов

## Устранение неполадок

### Частые проблемы и их решения

#### Проблемы с установкой зависимостей
- Обновите pip: `python -m pip install --upgrade pip`
- Установите зависимости по одной: `pip install numpy`, `pip install pandas` и т.д.

#### Проблемы с импортом модулей
- Убедитесь, что вы находитесь в корневой директории проекта
- Проверьте наличие всех файлов модулей
- Добавьте путь к PYTHONPATH: `export PYTHONPATH="${PYTHONPATH}:/path/to/ЛокальноеПриложение"`

#### Проблемы с памятью
- Закройте другие приложения
- Увеличьте виртуальную память в настройках Windows
- Обрабатывайте данные по частям

### Получение помощи

Если у вас возникли проблемы с использованием платформы:
