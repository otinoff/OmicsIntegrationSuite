# Установка и запуск локального приложения

## Системные требования

### Минимальные требования
- Операционная система: Windows 10 или выше
- Процессор: 4 ядра с частотой 2.5 ГГц или выше
- Оперативная память: 16 ГБ
- Дисковое пространство: 50 ГБ свободного места
- Python: 3.8 или выше

### Рекомендуемые требования
- Операционная система: Windows 10 Pro или выше
- Процессор: 8 ядер с частотой 3.0 ГГц или выше
- Оперативная память: 32 ГБ или больше
- Дисковое пространство: 100 ГБ свободного места (SSD рекомендуется)
- Python: 3.9 или выше

## Установка Python

Если Python еще не установлен на вашей системе:

1. Перейдите на официальный сайт Python: https://www.python.org/downloads/
2. Скачайте последнюю версию Python для Windows
3. Запустите установщик и следуйте инструкциям
4. Убедитесь, что во время установки выбрана опция "Add Python to PATH"

Проверьте установку Python, открыв командную строку и введя:
```bash
python --version
```

## Клонирование или скачивание репозитория

Если у вас установлен Git:
```bash
git clone <URL_репозитория>
cd ЛокальноеПриложение
```

Если Git не установлен, скачайте архив с репозиторием и распакуйте его.

## Установка зависимостей

Перейдите в директорию проекта и установите зависимости:

```bash
cd ЛокальноеПриложение
pip install -r requirements.txt
```

Или используйте скрипт установки:

```bash
python run.py --install
```

## Установка приложения (опционально)

Для установки приложения в систему как пакет Python:

```bash
pip install -e .
```

## Запуск приложения

### Запуск основного приложения

Для запуска основного приложения используйте один из следующих способов:

1. Через главный скрипт:
```bash
python main.py
```

2. Через скрипт запуска:
```bash
python run.py
```

### Запуск с параметрами командной строки

Приложение поддерживает различные параметры командной строки:

```bash
python run.py --help
```

Основные параметры:
- `--module` или `-m`: Выбор модуля для запуска (genomics, transcriptomics, mirna, proteomics, metabolomics, integration, qc, reporting)
- `--input` или `-in`: Путь к входным данным
- `--output` или `-out`: Путь к выходным данным
- `--gui` или `-g`: Запуск веб-интерфейса (если доступен)
- `--install` или `-i`: Установка зависимостей

Примеры запуска:

1. Запуск модуля обработки геномных данных:
```bash
python run.py --module genomics --input data/input/genomics --output data/output/genomics
```

2. Запуск модуля контроля качества:
```bash
python run.py --module qc --input data/input --output data/output/qc
```

### Запуск веб-интерфейса

Если установлен Streamlit, можно запускать веб-интерфейс:

```bash
python run.py --gui
```

Или напрямую через Streamlit:
```bash
streamlit run web_interface.py
```

## Решение частых проблем

### Проблемы с установкой зависимостей

Если возникают ошибки при установке зависимостей:

1. Обновите pip:
```bash
python -m pip install --upgrade pip
```

2. Попробуйте установить зависимости по одной:
```bash
pip install numpy
pip install pandas
# и так далее для каждой зависимости
```

### Проблемы с импортом модулей

Если возникают ошибки импорта модулей:

1. Убедитесь, что вы находитесь в корневой директории проекта
2. Проверьте, что все файлы модулей присутствуют
3. Убедитесь, что Python может найти модули, добавив путь к PYTHONPATH:
```bash
set PYTHONPATH=%PYTHONPATH%;C:\path\to\ЛокальноеПриложение
```

### Проблемы с памятью

Если приложение сталкивается с проблемами нехватки памяти:

1. Закройте другие приложения
2. Увеличьте виртуальную память в настройках Windows
3. Рассмотрите возможность обработки данных по частям
