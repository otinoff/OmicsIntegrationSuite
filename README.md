## Общее описание
Это локальное приложение для Windows 10 реализует платформу диагональной интеграции мультимодальных биологических данных. Приложение включает восемь основных модулей для обработки различных типов биологических данных.

Приложение было разработано в рамках контракта с ОСП РГНКЦ ФГАОУ ВО РНИМУ им. Н.И. Пирогова Минздрава России и завершено 11 сентября 2025 года.

## Требования к системе
- Windows 10 или выше
- Python 3.8 или выше
- Не менее 16 ГБ оперативной памяти
- Не менее 50 ГБ свободного места на диске

## Установка
1. Установите Python 3.8 или выше с официального сайта python.org
2. Склонируйте или скачайте этот репозиторий
3. Откройте командную строку в папке проекта
4. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Запуск приложения
Для запуска приложения выполните:
```
python main.py
```

## Модули приложения

### 1. Модуль обработки геномных данных (genomics)
Обрабатывает FASTQ, BAM/CRAM, VCF файлы

### 2. Модуль обработки транскриптомных данных (transcriptomics)
Обрабатывает bulk RNA-seq и scRNA-seq данные

### 3. Модуль обработки данных микроРНК (mirna)
Обрабатывает miRNA-seq данные

### 4. Модуль обработки протеомных данных (proteomics)
Обрабатывает RAW файлы масс-спектрометров

### 5. Модуль обработки метаболомных данных (metabolomics)
Обрабатывает MS данные и peak tables

### 6. Модуль диагональной интеграции (integration)
Объединяет данные различных модальностей

### 7. Модуль контроля качества (quality_control)
Обеспечивает качество данных на всех этапах

### 8. Модуль отчетности (reporting)
Генерирует унифицированные отчеты
